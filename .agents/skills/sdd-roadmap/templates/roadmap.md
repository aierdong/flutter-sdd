# 路线图模板（供人审阅）

<!--
Agent 把模板复制到 specs/pNN-<slug>-roadmap.md，再填写内容。

用法：
- Agent 替换尖括号 <> 内的占位文字，并删除尖括号。
- HTML 注释是写作提示，Agent 在定稿前删除。
- 第 1 节说明全部做完用户能做什么、以及不做什么；第 2 节说明怎样算完成、怎么验证。

- 路线图：`pNN`

- 版本：`v1`
