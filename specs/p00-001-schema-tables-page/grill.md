## 决策

起点（流程确认，不计入问题数）：用户选择从零重新访谈；旧草稿只作参考，不作为任何需求或决策依据。

Q1 这个页面在应用中的位置是什么？
A: 应用首屏/当前唯一页面；启动即显示；将来的 database→schema→table 树再替换或扩展它。
   放弃：只作为未来浏览页的内容区、需要外层树布局才能运行。
   何时重新评估：引入 database/schema 树时。
→ R1 / §2 / §5

Q2 表格列出哪个范围内的表？
A: 单个 schema；页面知道当前 schema，表格只列该 schema 的表；本期不做 schema 切换器。
   放弃：列出整个数据库所有 schema 的表、并增加 Schema 列。
   何时重新评估：需要跨 schema 浏览时。
→ R2 / R3 / §5

Q3 页头展示哪些连接信息？
A: 连接名 + 数据库名（如 `Local dev · myapp`）；不显示主机、端口、用户名；密码永不显示。
   放弃：`host:port` + 用户名；或只显示连接名。
   何时重新评估：同名连接指向不同实例、必须靠主机区分时。
→ R2 / §6

Q4 「新建连接」按钮做到什么程度？
A: 按钮可见但置灰不可点；本 spec 不定义点击行为。
   放弃：占位对话框、SnackBar、完整新建连接表单。
   何时重新评估：新建连接 spec 启动时。
→ R2 / §5

Q5 表格每行显示哪些列？
A: 六列：表名、类型、描述、列数、估算行数、大小；描述为空显示 `—`；大小用人类可读单位。
   放弃：四列（去掉描述与大小）。
   何时重新评估：需要精简视图或精确大小时。
→ R3 / §6

Q6 纯 UI spec 覆盖哪些页面状态？
A: 有数据、空、加载中、失败四态都做；失败态展示错误码；页头在四态都保留。
   放弃：只做有数据与空两态。
   何时重新评估：数据层改为同步取数、可去掉加载态时。
→ R4 / R5 / R6 / §6

Q7 界面文案用什么语言？
A: 中文；失败文案直接遵守 FSD-08，不改编码规范。
   放弃：英文界面；那需要把 FSD-08 改成英文格式并升 v2。
   何时重新评估：需要多语言时。
→ R2–R6 / §6

Q8 除了滚动，表格还要哪些交互？
A: 列排序与 `N 张表` 数量统计；不做搜索、刷新、行点击、分页。
   放弃：纯展示；或加入搜索/刷新。
   何时重新评估：表数量大到需要搜索定位时。
→ R7 / R8 / §5

Q9 排序做到什么程度？
A: 表名、类型、列数、估算行数、大小五列可排序；默认表名升序；首次点击升序、再点降序；大小按字节、行数按数值。
   放弃：仅表名排序；描述排序；多列排序。
   何时重新评估：用户要求按描述排序或多列排序时。
→ R8 / §6

Q10 运行应用时首屏用哪份数据评审？
A: 固定演示数据：`Local dev`、`myapp`、`public`、6 张表；不连接 PostgreSQL。
   放弃：首屏只显示空态。
   何时重新评估：数据层 spec 接入真实数据时。
→ R1 / R3 / R11 / §6

Q11 表很多、文本很长、窗口变窄时怎么处理？
A: 表格区域双向滚动，文本不截断；800×600 下无布局溢出；不分页、不虚拟滚动。
   放弃：省略号加 tooltip、分页、虚拟滚动。
   何时重新评估：窄窗口成为常态，或行数达到数千时。
→ R9 / §5

Q12 FSD-11 的严格分析器配置要不要并入本 spec？
A: 不并入；显式延期到后续 spec；本 spec 审查只按 format / analyze / test 三条判定，并在第 6 节记录延期。
   放弃：本 spec 补齐 strict 配置并修掉暴露的告警。
   何时重新评估：下一个代码交付 spec，或专门的规范配置 spec。
→ §6 / 规范触碰

反例检查（不计入问题数）：只列普通表、`类型` 显示 `Table` 会被违反吗？
A: 不会；列表只列普通表（分区表算表），视图与物化视图不做。
   放弃：视图、物化视图；`类型` 列本期只出现 `Table`。
   何时重新评估：扩展对象类型时。
→ R3 / §5

修订（用户直接指示，不计入问题数）：R4 由「空态不渲染表头」改为「空态保留六列表头，表体显示 `该 schema 下暂无表。`」；场景 B 与第 7 节建议同步调整；spec 版本升 v2。
→ R4 / §3 / §7

修订（用户选择方案 B，不计入问题数）：四态人工验收改用 `--dart-define=DEMO_STATE`，不增加调试 UI；默认 `data`，未设置或未知值回退 `data`；R11 改为默认演示数据 + 启动参数选择四态；§5 增加不做页面内状态切换；§6 增加四态人工验收决策；spec 版本升 v3。
→ R11 / §5 / §6 / §7
