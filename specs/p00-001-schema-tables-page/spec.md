## 1. 背景与问题

**现状**：仓库只有 `flutter create` 生成的骨架。`lib/main.dart` 仍是计数器模板页，`test/widget_test.dart` 是配套的计数器冒烟测试；`lib/` 下没有页面、领域模型或数据层；本 spec 创建前 `specs/` 为空。`docs/standards/coding.md:163` 的 FSD-05 要求首个 spec 交付前删除或替换计数器页与测试。`project.md` 定义的目标是只读浏览 PostgreSQL 库结构，但当前运行应用只能看到计数器。

**问题**：应用里看不到任何表，也没有一个能容纳表列表的页面骨架。后续接数据层的 spec 若先做，数据没有地方展示；若后做，又要把 UI 和取数逻辑一起改。FSD-05 也会一直悬空，因为模板页和测试还没有被替换。

**为什么现在做**：它是 p00 的第一个 spec，决定页面骨架、演示数据、交互边界与文案语言。先把 UI 定下来，后面的数据层 spec 只需要替换数据来源，不用重画页面。

## 2. 目标

- 让应用启动即进入「当前连接 + 单 schema 表列表」页面，而不是计数器。
- 让页面用同一个表格区域呈现有数据、空、加载中、失败四种状态。
- 让用户能按五列排序，并看到当前 schema 的表数量。
- 让页面在不连接 PostgreSQL 的前提下用固定演示数据直接评审。

**成功后，你能看到/做到**：运行应用，页头写着 `Local dev · myapp` 和 `public`，右侧有一个禁用的 `新建连接` 按钮；表格显示六列与 `6 张表`；点表头能改顺序；没有表时保留六列表头并在表体提示，加载中、失败时替换整个表格区域；应用里找不到计数器。

## 3. 用户场景

### 场景 A：启动、浏览与排序

1. 开发者启动应用（macOS 或 Windows）。
2. 应用直接进入本页，首屏显示 `Local dev · myapp`、`public` 和禁用的 `新建连接` 按钮。
3. 表格显示 `表名`、`类型`、`描述`、`列数`、`估算行数`、`大小` 六列与 6 行演示数据，表格上方显示 `6 张表`。
4. 点击 `大小` 表头，行按大小升序；再点一次，变为降序，表头方向标记随之切换。
5. 把窗口拉窄到 800×600，表格区域出现横向滚动；滚动后仍能读到完整的长表名与描述。

### 场景 B：schema 下没有表

1. 传入的表列表为空。
2. 六列表头仍然显示；表头下方的表格区域显示 `该 schema 下暂无表。`。
3. 数据行和 `N 张表` 不显示；页头的连接信息、schema 与 `新建连接` 按钮仍然可见。

### 场景 C：加载中与失败

1. 数据还没到：表格区域显示进度指示，不显示表格和数量统计；页头仍可见。
2. 数据加载失败：表格区域显示 `加载表失败（错误码：FSD-TABLE-001）`，不显示表格和数量统计；页头仍可见。
3. 失败文案不包含驱动异常原文、密码或完整连接串。

## 4. 必须做到

- [ ] **R1** 应用启动后直接显示本页，不再出现模板计数器页；模板计数器页与其冒烟测试被删除或替换。
  - **反例**：启动仍是计数器；页面存在但需要点击才出现；home 仍指向模板页；测试套件仍保留计数器冒烟测试。
  - **可观察证据**：运行应用首屏即连接信息与表格区域；应用内找不到计数器加号按钮与计数文案；测试套件里找不到计数器测试。

- [ ] **R2** 页头第一行显示 `<连接名> · <数据库名>`，第二行显示当前 schema 名；`新建连接` 按钮在页头右侧可见但处于禁用状态，点击不产生任何界面变化；页头不显示密码、主机、端口或用户名。
  - **反例**：只显示连接名；schema 名缺失或被写死成 `public`；按钮可点并弹出对话框、提示或跳转；出现密码、`host:port` 或用户名。
  - **可观察证据**：换一份连接名、库名、schema 名，页头文本随之变化；按钮呈禁用样式；页面文本中找不到密码、主机、端口、用户名。

- [ ] **R3** 传入 N（N > 0）张表时，表格每行对应一张表，列固定为 `表名`、`类型`、`描述`、`列数`、`估算行数`、`大小`，取值来自传入数据；`描述` 为空时显示 `—`；`类型` 显示传入的关系类型（本期演示数据为 `Table`）；`大小` 以 B/KB/MB/GB 等人类可读单位显示；行数等于 N。
  - **反例**：行数与 N 不符；缺列或多列；描述为空时该行消失或整页报错；列值在页面内硬编码而不是来自传入数据；大小显示原始字节数。
  - **可观察证据**：换一份表数据渲染，行数、表名和各字段值随之改变；空描述行显示 `—`；演示数据至少 6 张表，覆盖空描述、长表名、不同列数、行数与大小。

- [ ] **R4** 已加载但表数为 0 时，仍渲染六列表头；表头下方的表格区域显示 `该 schema 下暂无表。`，不渲染数据行和数量统计；页头仍显示连接信息、schema 与 `新建连接` 按钮。
  - **反例**：不渲染表头；把空态提示放在表格外并替换整个表格；显示 `0 张表`；空态与加载态看起来一样；页头消失。
  - **可观察证据**：六列表头可见；表头下方只有空态提示；没有数据行，也没有 `N 张表`；页头文本仍在。

- [ ] **R5** 加载中时，表格区域显示进度指示，不显示表格、数据行和数量统计；页头仍显示。
  - **反例**：加载中显示空白表格或上一份数据；进度指示出现在页头或其他区域；页头消失。
  - **可观察证据**：进度指示可见；表格与 `N 张表` 不可见；页头仍在。

- [ ] **R6** 失败时，表格区域显示 `<消息>（错误码：FSD-<AREA>-<NNN>）`，不显示表格、数据行和数量统计；消息与错误码来自传入的失败对象，不展示驱动异常原文；页头仍显示。
  - **反例**：只显示消息没有错误码；错误码不在同一段文案里；格式不是中文全角括号与 `错误码：`；失败时仍显示表格或旧数据；出现驱动异常原文、密码或完整连接串。
  - **可观察证据**：文本包含 `错误码：FSD-`；演示失败态显示 `加载表失败（错误码：FSD-TABLE-001）`；表格与数量统计不可见。

- [ ] **R7** 有数据时显示 `N 张表`（N 等于渲染出的行数），空、加载、失败态都不显示。
  - **反例**：N 与实际渲染行数不一致；空态显示 `0 张表`；加载或失败态仍显示数量统计。
  - **可观察证据**：文本与行数逐例对照；三种非数据态都找不到 `张表`。

- [ ] **R8** 有数据时，`表名`、`类型`、`列数`、`估算行数`、`大小` 五列表头可点击；点击后按该列升序排列，再点切换为降序，并在表头显示当前方向（`▲` 升序 / `▼` 降序）；`描述` 表头不可点击；默认按 `表名` 升序；文本按字典序，数值列按数值比较，`大小` 按字节比较；同一时间只有一列参与排序。
  - **反例**：`描述` 表头也可排序；`大小` 按 `1.2 MB` 字符串比较；连续点击同一列方向不变或方向标记标错；默认按传入顺序；两列同时显示排序方向。
  - **可观察证据**：点击表头后行的顺序变化，方向标记随之切换；默认首行是表名最小的行；`大小` 排序结果与数值顺序一致。

- [ ] **R9** 表很多（如 500 行）、表名或描述很长、窗口变窄时，表格区域可纵向和横向滚动；单元格文本不截断；在 800×600 窗口下不出现布局溢出；不分页、不启用虚拟滚动。
  - **反例**：窄窗口出现黄黑溢出条或抛异常；长表名或描述显示省略号；右侧列被裁掉且无法横向滚动；出现分页控件，或只渲染可视行导致滚动条长度失真。
  - **可观察证据**：横向滚动后能读到完整的长表名与描述；缩窄到 800×600 后界面无溢出提示；500 行时纵向滚动可到达最后一行。

- [ ] **R10** 点击或悬停数据行不产生选中态、不导航、不打开详情、不改变数据。
  - **反例**：行出现高亮或选中标记；点击行打开详情、对话框或新路由；悬停改变行内容。
  - **可观察证据**：点击行前后界面与路由不变；没有选中态或详情面板。

- [ ] **R11** 页面不连接 PostgreSQL、不读写数据库；连接信息、schema、表数据和状态均由外部传入；应用默认用固定演示数据渲染，四态可通过启动参数选择；运行时不发起网络或数据库请求。
  - **反例**：页面内引入 PostgreSQL 驱动并发起连接；启动时尝试连接数据库；表数据在页面内部硬编码而不是由调用方传入；没有数据库时页面无法显示；启动参数切换状态时触发数据库请求。
  - **可观察证据**：在无数据库、断网环境下，四种 `DEMO_STATE` 都能渲染对应状态；UI 层代码不引用 PostgreSQL 驱动；替换传入数据即可改变页面。

## 5. 明确不做

- 不做新建连接表单、对话框或页面；`新建连接` 按钮保持禁用。理由：本 spec 只画当前页面，连接管理是独立能力。
- 不做 schema 切换器、连接切换器或连接列表。理由：本页只显示一个当前连接与一个 schema，切换能力留给后续 spec。
- 不做连接状态指示（已连接/断开）或连接延迟显示。理由：本 spec 不连接数据库，状态无法真实反映；接数据层时再加。
- 不做搜索、过滤、刷新按钮、右键菜单、导出 CSV、列宽拖拽、列顺序调整、列显隐。理由：首版只验证表格展示与排序，避免把页面做成工具箱。
- 不做页面内的状态切换按钮、调试面板或调试路由；四态只通过启动参数选择。理由：调试 UI 会进入产品页面并扩大范围，`--dart-define` 已足够人工验收。
- 不做分页与虚拟滚动。理由：500 行以内桌面滚动足够；性能在 `project.md` 的取舍中排最后。
- 不做行选中、悬停高亮、表详情、字段列表、约束、外键、索引面板。理由：详情是后续 spec，本 spec 保持纯展示。
- 不做视图、物化视图、外部表；列表只包含普通表（分区表算表）。理由：用户通过反例检查确认本期范围；扩展对象类型时再加。
- 不做真实数据库连接、元数据查询、连接配置持久化、失败重试。理由：本 spec 明确 UI-only，数据由外部传入。
- 不做深色/浅色主题切换、i18n 框架、移动端布局。理由：桌面应用，文案固定中文，引入主题或 i18n 会扩大范围。
- 不实现 FSD-11 的 strict-casts、strict-inference、strict-raw-types 与额外 lint 配置。理由：用户明确选择显式延期到后续 spec，见第 6 节。
- 不改变 `flutter analyze`、`flutter test` 的命令入口，也不改变只读目标库约束。理由：回归保护；本 spec 不连接数据库，但仍不写目标库。

## 6. 风险与取舍

| 决策 | 选择 | 理由 | 放弃了什么 | 何时重新评估 |
|---|---|---|---|---|
| 页面状态覆盖面 | 有数据、空、加载、失败四态都做 | 数据层接入时页面不用重写 | 更少的状态建模 | 数据层改为同步取数时 |
| 表范围 | 单 schema、仅普通表（分区表算表） | 首版聚焦用户确认的范围 | 跨 schema 浏览、视图与物化视图 | 需要浏览其他对象类型时 |
| 连接信息 | 只显示连接名与数据库名 | 足够确认当前连接，避免展示主机与用户名 | `host:port`、用户名 | 同名连接指向不同实例且需要区分时 |
| 新建连接 | 按钮禁用 | 没有表单可去，假交互会误导 | 点击反馈与占位对话框 | 新建连接 spec 启动时 |
| 表格列与格式 | 六列；描述空显示 `—`；大小人类可读 | 信息完整且可读 | 精简四列、原始字节 | 需要精确大小或精简视图时 |
| 排序 | 五列可排序，默认表名升序 | 覆盖常用定位方式，描述过长不参与排序 | 描述排序、多列排序 | 用户要求按描述或多列排序时 |
| 溢出策略 | 双向滚动、文本不截断 | 保证信息完整，不隐藏内容 | 省略号加 tooltip、分页、虚拟滚动 | 窄窗口成为常态或行数达到数千时 |
| 首屏数据 | 默认固定演示数据，不接 PostgreSQL；四态可用启动参数切换 | 让 UI 可直接评审，符合 UI-only | 真实连接与真实元数据 | 数据层 spec 接入时 |
| 四态人工验收 | 用 `--dart-define=DEMO_STATE` 选择 `data`、`loading`、`empty`、`error`；默认 `data`，未设置或未知值回退 `data`；不增加调试 UI | 页面保持干净，不引入调试组件，也不触发 FSD-02 的支持代码边界 | 一键切换的便利；每次换状态需重启应用 | 接数据层后由真实数据状态替代，删除该 define 分支 |
| 文案语言 | 中文 | 与 FSD-08 现有错误码格式一致，避免改规范 | 英文界面、i18n 框架 | 需要多语言时 |
| 分析器配置 | 不在本 spec 实现 FSD-11 严格配置，显式延期 | 用户选择把范围限制在 UI，避免夹带无关告警修复 | 本 spec 交付即完全符合 FSD-11 | 下一个代码交付 spec 或专门的规范配置 spec |
| 依赖 | 只用 Flutter 内置组件 | FSD-12 禁止新增无关依赖，内置表格足够 | 第三方数据表格或虚拟滚动库 | 内置组件无法满足交互或性能时 |

## 7. 审阅问题

**必须你决定**：本次无需你决定的事项。

**建议确认**：

- 空态保留六列表头，只在表体显示 `该 schema 下暂无表。`；加载、失败态替换整个表格区域；页头的连接信息、schema 与禁用的 `新建连接` 按钮在四态都保持可见。
- 失败态演示文案固定为 `加载表失败（错误码：FSD-TABLE-001）`，错误码来自集中定义的码表。
- `类型` 列本期只出现 `Table`；保留该列是为了后续扩展对象类型，若希望本期去掉该列，请在批准时说明。
- 演示数据使用 `Local dev`、`myapp`、`public` 和 6 张表；具体表名与数值由 plan 选定，但必须覆盖空描述、长文本、不同列数、行数与大小。
- 四态人工验收用 `--dart-define=DEMO_STATE` 切换（`data`、`loading`、`empty`、`error`）；默认 `data`，未设置或未知值回退 `data`；这是开发辅助，不是页面上的产品控件。
