## 决策

#### 输入：用户最初提出的取舍
- 问题：实现技能应保留哪些质量步骤。
- 决定：不强制 TDD，不需要测试的就不测试；只检查相关部分，默认集中执行，不为每个任务追加测试或审查，计划没有要求测试就不增加测试。
- 放弃：所有任务都执行红绿循环、重复前置验证和逐任务审查。
- 何时重新评估：用户明确改变质量要求时。
- 对应：R2、R3、R4、R10

#### Q1：本次与其他内容的调整顺序
- 问题：是否同时调整流程入口、计划技能及其模板和校验。
- 决定：用户要求分两步。先解决 `sdd-impl` 本身的设计，再处理其他内容；已有技能可以迭代，Demo 和设计副产品不构成约束。
- 放弃：先迁就现有规则，或在实现技能尚未定型时同步修改所有周边内容。
- 何时重新评估：实现技能设计基本完善，进入用户指定的同步调整步骤时。
- 对应：§1、§5、§6 决策 1

#### Q2：计划外的编译、静态检查与 lint
- 问题：计划没有安排测试时，Agent 是否可以自行运行其他检查。
- 决定：用户选择全部以计划为准；未安排的不自行运行，确有必要时说明原因，由用户决定是否补入计划。
- 放弃：将非测试检查视为实现 Agent 的默认自由操作。
- 何时重新评估：用户明确授权新增检查时。
- 对应：R2、§6 决策 2

#### Q3：检查失败后的修复权限
- 问题：不改变需求、方案和授权范围的修复是否需要逐次确认。
- 决定：用户允许自行修复并定向重跑，只覆盖失败项及修复直接影响的、已安排的检查，不默认全量重跑。
- 放弃：每次修复和重跑前都暂停请用户确认。
- 何时重新评估：修复需要改变上游或扩大授权时。
- 对应：R8

#### Q4：独立实现记录
- 问题：实现结束是否单独生成记录文件。
- 决定：用户选择不生成；更新任务勾选，在对话中说明实际改动、检查结果和未完成事项，不强制保存原始输出、截图或日志。
- 放弃：额外实现报告与证据归档要求。
- 何时重新评估：用户或计划明确要求相关产物时。
- 对应：R11、§6 决策 5

#### Q5：集中检查前的任务勾选
- 问题：实现改动已完成、末尾统一检查尚未执行时是否先勾选。
- 决定：用户允许先勾选实现任务，检查任务单独记录；实现已勾选不等于检查通过。
- 放弃：所有任务必须等待最后检查通过才一起勾选。
- 何时重新评估：用户改变任务进度记录方式时。
- 对应：R6

#### Q6：必要辅助文件
- 问题：完成现有任务必须新增清单之外的辅助文件时是否需要先修订计划。
- 决定：用户允许自行新增，不改变需求或方案，并在交付中说明。
- 放弃：把文件清单作为封闭白名单，任何必要新增都重新批准。
- 何时重新评估：新增文件实际引入新功能、改变方案或超出现有任务时。
- 对应：R7、§6 决策 4

#### Q7：自动修复次数
- 问题：计划内检查失败后的自动修复与重跑是否设置上限。
- 决定：用户指定最多三轮；每轮是修复后定向重跑，首次执行检查不计入。
- 放弃：无限自动修复，以及提问选项中的两轮上限。
- 何时重新评估：达到上限，由用户决定下一步时。
- 对应：R9

#### Q8：轮次累计范围
- 问题：三轮额度按整次实现还是独立问题累计。
- 决定：用户选择每个独立失败问题各三轮；同一问题跨任务和恢复会话累计，不重新计数。
- 放弃：所有失败共用三轮额度，或通过切换任务重置额度。
- 何时重新评估：用户明确改变成本限制时。
- 对应：R9、§6 决策 4

#### Q9：实现后的审查交接
- 问题：实现任务和计划内检查完成后是否自动启动 `sdd-review`。
- 决定：用户选择自动交接，不再等待一次确认；审查通过前只宣称实现阶段完成。技能不可用时报告交接受阻，不编造审查流程。
- 放弃：每次实现结束后等待用户另行启动审查，以及逐任务插入审查。
- 何时重新评估：审查技能可用性或交接方式变化时。
- 对应：R10、R12、§6 决策 6

#### Q10：复用已有检查结果
- 问题：用户或前序任务提供的结果能否满足计划内检查。
- 决定：用户允许复用仍适用于当前代码和相关环境、且未因后续改动失效的结果，不要求当前 Agent 亲自再执行。
- 放弃：因为执行者不同或来自前一个任务，就拒绝已有结果。
- 何时重新评估：计划明确禁止复用，或结果失效时。
- 对应：R5、§6 决策 3

#### Q11：Git 提交与复用默认值补充
- 问题：是否把创建 Git 提交作为默认实现步骤。
- 决定：用户选择不自动提交。同时补充 Q10：结果可复用是默认行为，只有计划明确说明前次检查结果不能复用时才不复用。
- 放弃：默认自动提交，以及只有显式授权才允许复用的解释。
- 何时重新评估：用户或计划明确要求提交，或明确禁止结果复用时。
- 对应：R5、R11

#### 反向检查：防止换名追加成本
- 问题：是否默认添加独立实现报告、原始输出归档、自动提交或逐任务独立审查。
- 决定：不添加。用户分别在最初要求、Q4 和 Q11 排除了这些默认行为；不得改称“自检”或“留证”后重新加入。
- 放弃：为了完整流程而附带增加的产物和操作。
- 何时重新评估：用户或计划明确要求对应操作时。
- 对应：R2、R10、R11、§5
